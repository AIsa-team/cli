# AIsa for VS Code

Adds AIsa's models (Claude, GPT, DeepSeek, Kimi, GLM, Qwen) to VS Code chat
using the credential `aisa login` stores. Installed by
`aisa connect`; nothing to paste. The bundled extension may read the CLI
compatibility mirror internally. Users and agents must not copy credential
files. Run **AIsa: Set up AIsa models in chat**
from the command palette to re-provision after rotating your key.
