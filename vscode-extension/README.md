# AIsa for VS Code

Adds AIsa's models (Claude, GPT, DeepSeek, Kimi, GLM, Qwen) to VS Code chat
using the key `aisa login` stored in `~/.aisa/key`. Installed by
`aisa connect`; nothing to paste. Run **AIsa: Set up AIsa models in chat**
from the command palette to re-provision after rotating your key.
